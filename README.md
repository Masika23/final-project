# final-project

🍰 Minnie's Bakery Website

📌 Project Overview

Minnie's Bakery Website is a responsive multipage website created using HTML5, CSS3, and JavaScript. The website showcases a bakery’s services, menu items, and contact information in an interactive and user-friendly way.

The project demonstrates:

Semantic website structure with HTML5

Styling and responsive design with CSS3

Interactivity with JavaScript (form validation, image slider, etc.)

Deployment using GitHub Pages / Netlify / Vercel

🎨 Features
